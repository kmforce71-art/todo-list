## 1. 주요 기능

1. **할 일 등록**:
   - `Enter` 키 또는 `추가` 버튼으로 등록
   - 앞뒤 공백 자동 제거(`trim`) 및 빈 문자열/공백만 있는 입력 방지
   - 최대 200자 제한 및 실시간 글자 수 카운터 표시 (`0/200`)
   - 한글 IME 조합 중 `Enter` 시 의도치 않은 중복 등록 방지 (`isComposing` 감지)
   - 등록 완료 후 입력창 자동 초기화 및 포커스 유지
   - 최신 등록 항목이 목록 최상단에 배치
2. **완료 상태 관리**:
   - 체크박스 또는 할 일 텍스트 클릭으로 완료/미완료 토글
   - 완료 항목 취소선 및 감쇠 텍스트 스타일 적용
   - 헤더 진행률 막대(`role="progressbar"`) 및 통계에 실시간 반영
3. **인라인 내용 수정**:
   - 항목별 `수정` 버튼 클릭 시 인라인 입력 모드로 전환
   - `Enter` 또는 `저장` 버튼으로 반영, `Esc` 키 또는 `취소` 버튼으로 취소
   - 공백 내용 저장 차단 및 유효성 오류 안내
   - 수정 완료/취소 후 원래의 `수정` 버튼으로 포커스 복귀
4. **개별 삭제 및 실행 취소 (Undo)**:
   - `삭제` 버튼 클릭 시 목록에서 즉시 제거
   - 화면 하단에 실행 취소 스낵바 노출 (`role="status"`, "할 일을 삭제했어요.")
   - `실행 취소` 클릭 시 원래 ID, 내용, 완료 여부, 생성일시, 정렬 위치 그대로 복원
   - 연속 삭제 시 최신 삭제 1건에 대해 명확한 실행 취소 지원
5. **상태 필터 및 검색**:
   - 필터: `전체`, `진행 중`, `완료` (접근성 `aria-pressed` 속성 적용)
   - 검색: 대소문자 무관 부분 일치 검색
   - 필터와 검색 조건의 교집합(AND) 적용
   - 검색어 초기화 원클릭 버튼 제공
   - 전체 데이터 없음 / 조건 결과 없음 / 검색 결과 없음 상태 구분 UI 제공
6. **완료 항목 일괄 삭제**:
   - 완료 항목이 없을 때 버튼 비활성화(`disabled`)
   - 클릭 시 확인 대화상자(`<dialog>` 네이티브 모달) 노출 (삭제 대상 개수 명시)
   - `취소` 또는 배경 클릭 시 데이터 보존 및 모달 닫기
7. **데이터 자동 저장 및 장애 복원**:
   - 브라우저 `localStorage` 기반 자동 저장 및 새로고침 복원
   - 스키마 버전(`schemaVersion: 1`) 포함 및 데이터 무결성 검증
   - 손상된 JSON이나 비정상 데이터 진입 시 원본 데이터를 덮어쓰지 않고 보호하며 복구 안내 제공
   - 저장 실패(용량 초과 등) 시 사용자에게 경고하고 인메모리 사용 유지

## 2. 저장 방식 및 제한사항

- **저장 범위**: 본 앱의 데이터는 사용자의 **현재 웹 브라우저 로컬 저장소(`localStorage`)**에만 보관됩니다.
- **클라우드 및 계정 동기화 미지원**: 백엔드 서버나 외부 데이터베이스, 클라우드 백업이 없으므로 다른 브라우저, 다른 기기, 시크릿 창과는 데이터가 공유되지 않습니다.
- **다중 탭 동기화 제한**: 여러 브라우저 탭에서 동시에 편집하는 경우 최종 저장된 상태를 기준으로 덮어쓰일 수 있습니다.

## 3. 실행 및 검증 방법

### 요구사항
- Node.js (v18 이상 권장)
- npm

### 1) 의존성 설치
```bash
npm install
```

### 2) 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:5173`으로 접속합니다.

### 3) 프로덕션 빌드 및 미리보기
```bash
# 프로덕션 빌드 (TypeScript 컴파일 + Vite 번들링)
npm run build

# 빌드 결과물 로컬 서빙
npm run preview
```

### 4) 테스트 실행
```bash
# Vitest 단위 및 통합 테스트 (총 28개 테스트 전체 통과)
npm test
```

## 4. 파일 구조
- `DESIGN.md`: 디자인 시스템 명세 및 가이드
- `src/types/todo.ts`: 데이터 모델 및 스토리지 타입
- `src/styles/tokens.css`: CSS Custom Properties 기반 디자인 토큰
- `src/styles/global.css`: 리셋, 반응형 레이아웃, 접근성 스타일
- `src/lib/storage.ts`: 로컬 스토리지 입출력 및 스키마 검증
- `src/lib/date.ts`: 로컬 한국어 날짜 포맷팅
- `src/hooks/useTodos.ts`: 할 일 상태 및 비즈니스 로직
- `src/components/`: UI 컴포넌트 (`Header`, `TodoInput`, `TodoFilter`, `TodoList`, `TodoItem`, `TodoSummary`, `ConfirmDialog`, `UndoToast`, `Icons`)
- `src/test/`: 스토리지, 커스텀 훅, 컴포넌트 통합 테스트 코드
